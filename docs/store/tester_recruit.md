## 2. 구글 그룹 만들기
1. 브라우저에서 **groups.google.com**에 접속, Play Console 계정과 같은 구글 계정으로 로그인
2. **그룹 만들기**
   - 그룹 이름: 워치노트 테스터
   - 그룹 이메일: 예) `watchnote-testers` (→ `watchnote-testers@googlegroups.com`)
   - 그룹 설명: 워치노트 비공개 테스트 참여자
3. 개인정보 설정(그룹 설정):
   - **멤버 목록 보기 권한: 그룹 관리자만** (테스터끼리 이메일이 보이지 않게)
   - 그룹에 가입하는 방법: 초대받은 사람만
4. **멤버 → 멤버 추가(직접 추가)**: 받은 지메일 주소를 한 줄에 하나씩 붙여넣고 추가 (초대 메일 보내기는 끄고 직접 추가가 편함)
5. 만든 그룹 이메일 주소를 Play Console 비공개 테스트 → 테스터 탭에 입력 (인증 끝난 뒤)
