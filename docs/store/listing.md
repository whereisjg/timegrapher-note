# Play 스토어 등록정보 (한국어)

## 앱 이름 (최대 30자)
워치노트 - 시계 오차 측정 타임그래퍼

## 간단한 설명 (최대 80자)
휴대폰 마이크로 기계식 시계의 하루 오차·진폭·비트 에러를 재고, 시계별로 기록하세요.

## 자세한 설명 (최대 4,000자)
워치노트는 휴대폰 마이크로 기계식 시계의 '틱' 소리를 듣고 시계 상태를 계산하는 앱입니다. 매장에 가지 않고도 내 시계가 하루에 몇 초 빠르거나 느린지 확인할 수 있습니다.

■ 이런 값을 잽니다
• 하루 오차(초/일): 시계가 하루에 얼마나 빠르거나 느린지, 계산 오차 범위(±)와 함께 보여 줍니다
• 진폭(°): 밸런스 휠이 얼마나 크게 흔들리는지. 태엽 상태와 무브먼트 컨디션을 가늠하는 값입니다
• 비트 에러(ms): '틱'과 '톡' 간격이 얼마나 고른지
• 트레이스 그래프와 평균 틱 파형: 측정이 안정적인지 눈으로 확인

■ 시계 보관함
• 시계마다 무브먼트, bph, 리프트 앵글, 스탬핑 날짜, 메모를 저장
• 시계별 최근 측정과 기록을 한눈에
• 자세별(다이얼이 천장·바닥, 용두가 천장·바닥 등) 평균 오차 비교 (프로)

■ 측정 방법
1. 조용한 곳에서 시계 뒷판이나 옆면을 휴대폰 아래쪽 마이크 구멍에 붙입니다
2. '실시간 측정 시작'을 누르고 30~60초 기다립니다
3. 결과를 기록에 저장하고, 자세를 바꿔 가며 비교해 보세요
• 블루투스 이어폰이 연결되어 있어도 휴대폰 내장 마이크로 측정합니다
• 이미 녹음해 둔 파일(m4a, mp3, wav)도 분석할 수 있습니다

■ 무료와 프로
무료: 실시간 측정과 파일 분석(또렷한 신호), 시계 1개 등록, 최근 측정 기록 5개 보기
프로(한 번 결제): 약한 신호도 계산(케이스가 두꺼운 조용한 시계), 시계 무제한 등록, 기록 전체 보기와 자세별 평균
같은 구글 계정이면 다른 휴대폰에서도 프로가 복원됩니다.

■ 알아 두세요
• 휴대폰 녹음 회로의 시계에도 하루 1~3초 정도 오차가 있을 수 있습니다. 며칠간 실제 시각과 비교한 값이나 매장 타임그래퍼 결과가 있다면 '휴대폰 보정값'으로 맞출 수 있습니다
• 진폭은 휴대폰 마이크 특성상 참고값입니다
• 기계식 시계는 자세와 태엽 상태에 따라 실제 오차가 달라집니다. 하루 평균을 알려면 여러 자세에서 재 보세요
• 쿼츠(배터리) 시계는 측정할 수 없습니다

■ 개인정보
소리는 휴대폰 안에서만 분석하며 어디로도 보내지 않습니다. 광고와 추적 도구가 없습니다.
