# Play Console 입력 답안 (워치노트)

앱 기능이 바뀌면 이 문서도 맞춰 고칠 것. 구글 화면 문구는 자주 바뀌므로 비슷한 항목을 찾아 입력.

## 1. 앱 만들기
- 앱 이름: 워치노트 - 시계 오차 측정 타임그래퍼 (30자)
- 기본 언어: 한국어 (대한민국) — 영어·일본어·독일어·중국어 간체는 스토어 번역 준비되면 추가
- 앱 또는 게임: **앱**
- 무료 또는 유료: **무료** (프로는 인앱 구매)
- 선언: 개발자 프로그램 정책, 미국 수출법 동의

## 2. 스토어 등록정보
- 간단한 설명·자세한 설명: `listing.md`
- 아이콘 512: `icon_512.png` / 그래픽 이미지: `feature_1024x500.png`
- 휴대전화 스크린샷: `screenshots/1~6` (순서대로)
- 카테고리: 도구 (또는 라이프스타일) / 태그: 시계, 도구
- 연락처 이메일: 개발자 이메일(공개됨) / 개인정보처리방침: https://claude.ai/artifact/JaLhzRRS3HtuCX1e4V5The

## 3. 앱 콘텐츠 설문
- **개인정보처리방침 URL**: 위 주소
- **광고**: 광고 없음
- **앱 액세스**: 모든 기능을 별도 로그인 없이 사용 가능 (프로 기능은 구매로 열림. 테스트 시 라이선스 테스트 계정 사용)
- **콘텐츠 등급**: 설문에서 폭력·성적 내용·도박 등 모두 '아니요' → 전체 이용가 예상
- **타겟층**: 만 18세 이상 (아동 대상 아님)
- **뉴스 앱**: 아님 / **정부 앱**: 아님 / **금융 기능**: 없음 / **건강 앱**: 아님
- **데이터 보안**: 아래 4번

## 4. 데이터 보안 양식 (제출 전 구글 화면에서 정의를 다시 확인)
- 앱이 수집하거나 공유하는 필수 사용자 데이터 유형: **아니요(수집 없음)** — 마이크 소리는 기기 안에서만 분석하고 외부로 전송하지 않음, 시계·기록도 기기에만 저장
- 데이터 암호화 전송: 해당 없음(전송 없음) / 데이터 삭제 요청 경로: 앱 삭제 시 기기에서 삭제
- 참고: 안드로이드 자동 백업(Google 계정)이 켜져 있음. 구글은 시스템 자동 백업을 개발자의 '수집'으로 세지 않는 것으로 알고 있으나 양식의 설명을 읽고 확인할 것. 개인정보처리방침에 자동 백업과 알림을 적어 둠(2026-11-24)
- 인앱 결제는 Google Play 결제가 처리(앱은 카드 정보를 받지 않음)

## 5. 권한 선언
- 마이크(`RECORD_AUDIO`): 핵심 기능(시계 소리 측정)
- 알림(`POST_NOTIFICATIONS`): 오버홀 시기 알림(사용자가 켠 경우에만 요청)
- 부팅 완료 수신(`RECEIVE_BOOT_COMPLETED`): 재부팅 뒤 알림 일정 복원

## 6. 인앱 상품
- 상품 ID `pro_unlock`, 관리형(일회성) 상품, 제안가 ₩3,900
- 이름: 프로 업그레이드 / 설명: 약한 신호 측정, 시계 무제한 등록, 기록 전체 보기와 자세별 평균
- AAB를 올린 뒤에야 만들 수 있음

## 7. 비공개 테스트
- 테스터 12명 이상, 14일 연속 (구글 그룹 이메일로 등록). 개인 계정은 앱마다 필요
- 테스트 트랙에 AAB 업로드 → 테스터에게 참여 링크 공유
